# Clean one-minute demo

Eight 7.5-second scenes captured directly from `/demo1min`. The composition is a
literal two-column grid: text on the left and an unobscured interface capture on
the right. It uses no gradient, fog, tint, translucent scrim, or image overlay.

```bash
./promo/demo1min/assemble.sh
open promo/demo1min/final/sovereign-lens-demo-loop-60s.mp4
```
