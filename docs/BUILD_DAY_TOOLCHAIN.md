# Build Day toolchain and provenance

Long Horizon Agents Build Day · AGI House · August 22, 2026

## Baseline disclosure

The project concept, README specification, and early schemas existed before the
event. There was no working application baseline. Every executable prototype
module and public demo surface listed below was built and integrated on location
during the build day.

## Proposed 30-second toolchain film

- **00–05:** an empty evidence ledger becomes a temporal graph.
- **05–12:** capital, talent, compute, infrastructure, standards, and institutions
  appear as write events against a receiving state's Horizon.
- **12–20:** Qwen, GLM, DeepSeek, and Codex analyze the same write; phrases align
  and diverge without collapsing into one answer.
- **20–27:** later evidence resolves a prediction and updates the methodology ledger.
- **27–30:** Strategy Atlas zooms into Horizon Studio. Closing line: “The Horizon
  already exists. Make its programming observable.”

The film should show the instrument and its objects, not people presenting at a
planning board. Provider logos may appear only as small provenance labels attached
to actual runs or production steps.
